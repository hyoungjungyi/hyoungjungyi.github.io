# Hyun Jung (Haley) Yi — CV

Single-page, static CV site. No build step, no dependencies.

## Run locally

```
python3 -m http.server 8080
```

Then open http://localhost:8080 in a browser.

## Structure

```
index.html   the whole page (sections: Education, Publications, Research, Work, Awards, Skills)
style.css    light, minimal resume theme
assets/      profile photo, contact icons, one linked PDF
```
